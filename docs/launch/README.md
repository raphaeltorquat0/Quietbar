# Rascunhos de lançamento

Nada aqui foi publicado ou enviado. Antes de usar, confira:

- **Teste em hardware:** os textos dizem que os comandos de escrita ainda não passaram pelo roteiro completo. Depois de rodar `docs/HARDWARE_TEST.md`, atualize esse trecho.
- **Notarização:** os textos dizem que o app ainda não é notarizado. Se você notarizar antes de postar, remova o aviso.
- **Motivação:** os trechos entre colchetes pedem a sua história real. Não publique com colchetes.
- **Regras das comunidades:** confira as regras atuais de cada subreddit e do Product Hunt no dia de postar, porque mudam com frequência.
