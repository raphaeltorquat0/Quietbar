# Security

Quietbar talks to your headphones over local Bluetooth. It uses the internet for the daily update check through Sparkle, where every update is verified with an EdDSA signature, and for anonymous metrics, opt-in, off by default (see [docs/PRIVACY.md](docs/PRIVACY.md)).

## Report a vulnerability

Don't open a public issue. Use [Report a vulnerability](https://github.com/raphaeltorquat0/Quietbar/security/advisories/new) on GitHub, with the affected version and the steps to reproduce.

This is a project maintained by one person in their spare time, so there's no guaranteed response time.

## Supported versions

Only the latest release receives fixes.
